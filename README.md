# 喵尾巴 MiaoTail

一个只在句末补后缀的安卓小工具：在 QQ / 微信里打「今天天气不错。」，发出去变成「今天天气不错喵。」。

后缀、触发标点、生效的应用都能自己改，默认只对微信 / QQ / TIM 生效。

![示例：今天天气不错喵。](docs/example.svg)

> **公开项目，娱乐用途。** 本软件会改写输入框里的文字，请仅在设备所有者知情并同意的前提下安装。详见 [使用前提与免责声明](#使用前提与免责声明)。

## 它是怎么工作的

一个 `AccessibilityService` 监听输入框的文本变化事件，发现句末标点就在标点前插入后缀，再用 `ACTION_SET_TEXT` 写回、`ACTION_SET_SELECTION` 恢复光标。

不修改输入法、不替换键盘、不申请网络权限。装上、开无障碍、就能用；关掉无障碍或卸载就彻底停用。

## 安全与隐私

- **没有申请 `INTERNET` 权限**：APK 在系统层面就无法建立网络连接，不存在"偷偷上传"的可能
- 不读写聊天记录，不落盘、不缓存输入内容；只在文本变化事件里取当前输入框的文字，改写后立即丢弃
- 所有设置存在本机 `SharedPreferences`，`allowBackup=false`，卸载即清除
- 没有任何统计、上报、崩溃收集 SDK

### 自己核对一遍

- **图形界面**：设置 → 应用 → 喵尾巴 → 权限，里面不应出现「网络」相关权限
- **命令行**（可选）：
  ```sh
  adb shell dumpsys package com.meow.tail | grep -i permission
  ```
  同样不应出现 `android.permission.INTERNET`

## 安装

1. 到 [Releases](../../releases) 下载最新的 `app-debug.apk`
2. 手机上点开安装，允许「安装未知应用」
3. 打开「喵尾巴」，点「去开启无障碍」→ 找到 **喵尾巴 · 句尾补字** 并开启
4. 首次启动会弹一次知情提示，确认后就可以用了

> 只从本仓库的 Release 下载。第三方站点可能重打包并加入额外权限或广告，那不是本项目发布的版本。

## 使用

| 设置项 | 说明 |
| --- | --- |
| 后缀 | 想加什么就加什么，默认「喵」，最长 12 个字符 |
| 触发标点 | 哪些句末符号会触发补字，默认 `。！？!?～` |
| 所有应用都生效 | 关掉时只对下面列表里的应用生效 |
| 生效的应用包名 | 默认 `com.tencent.mm`（微信）、`com.tencent.mobileqq`（QQ）、`com.tencent.tim`（TIM） |
| 总开关 | 一键停用，不用卸载 |

### 行为细节

- 后缀插在标点**前面**：`你好。` → `你好喵。`
- 以**最后一个句末标点**为准；该标点前后已经带后缀的句子不会重复插入
- 两条检测通道：无障碍事件 + 每 400ms 轮询一次焦点输入框（部分 App 不广播文本事件，靠轮询兜底）
- 只响应「新增文字」，退格删除不会再被补回来
- 密码框、非输入框、本应用内的输入框会自动跳过
- 粘贴一整段文字时，只处理最后一句的句末标点
- 语音转文字、手写输入不一定触发（取决于是否产生标准文本变更事件）

### 诊断

设置页最下方有「诊断」卡片，记录最近 40 条事件与决策（时间、包名、事件类型、写入成功/失败）。排查「某 App 里不生效」时：

1. 去那个 App 打一句带句号的话
2. 回「喵尾巴」看诊断卡片，有没有出现该 App 的包名
3. 点「复制日志」可以直接发给开发者

如果一条记录都没有，说明无障碍服务没在运行；如果只有事件没有「补字成功」，说明写回被该 App 拒绝了。

## 已知限制

- 依赖无障碍服务，**不是输入法**：部分 App 的自绘输入框、网页表单可能只上报窗口事件而不上报文本事件，此时不会补字
- 光标在句子中间时，插入点之后的位置会整体右移（已做映射），个别 App 仍可能把光标跳到末尾
- 只改文字，表情、图片、语音消息不受影响
- 仅支持 Android 7.0（API 24）及以上；不支持 iOS

## 常见问题

**Q：为什么微信 / QQ 里有时不生效？**
A：先确认无障碍服务还在运行（部分国产 ROM 会在重启后自动关闭），再确认当前 App 在生效列表里。个别版本的输入框是自绘控件，无障碍拿不到文本事件，这种情况目前无解。

**Q：会不会把我的聊天内容传出去？**
A：不会。APK 没有 INTERNET 权限，没有服务器，也没有任何上报代码。可以按上面「自己核对一遍」验证。

**Q：怎么彻底关掉？**
A：三种方式，任选：App 里关总开关 → 系统设置里关掉无障碍权限 → 直接卸载。

**Q：为什么不上架应用商店？**
A：无障碍权限在 Google Play 的审核极严，这类娱乐用途基本过不了。本项目通过 GitHub Releases 分发，侧载安装。

**Q：可以改成别的话术吗？**
A：可以，App 里直接改后缀。改代码也欢迎，见下方编译说明。

## 编译

工程是标准 Gradle 项目（AGP 8.5.2 / Kotlin 1.9.24 / compileSdk 34），没有第三方依赖，不需要 AndroidX。

**Android Studio**：`File → Open` 选 `miaotail/` 目录 → sync → `Build → Build APK(s)`，产物在 `app/build/outputs/apk/debug/app-debug.apk`。

**命令行**：JDK 17 + Gradle 8.7+，执行 `gradle assembleDebug`。

**云端**：仓库内置 GitHub Actions 工作流（`.github/workflows/build.yml`）。推代码即自动编译，也可以在 Actions 页面手动 Run workflow。产物在运行记录的 Artifacts 里，同时会发布到 Releases。
